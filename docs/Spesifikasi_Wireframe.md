# Spesifikasi Wireframe ITAdvance

## 1. Halaman Login
Halaman untuk pengguna masuk ke aplikasi menggunakan email dan password.

Komponen:
- Kolom email.
- Kolom password.
- Tombol Login.
- Tautan Registrasi.

## 2. Halaman Registrasi
Halaman untuk membuat akun baru.

Komponen:
- Kolom nama.
- Kolom email.
- Kolom password.
- Tombol Daftar.

## 3. Halaman Preferensi Belajar
Halaman untuk mengisi minat dan kemampuan belajar pengguna.

Komponen:
- Pilihan bidang IT.
- Pilihan tingkat kemampuan.
- Input jam belajar per minggu.
- Tanggal target kelulusan.
- Tombol Simpan.

## 4. Halaman Dashboard
Halaman utama yang menampilkan ringkasan aktivitas belajar.

Komponen:
- Informasi pengguna.
- Tombol Check-in Harian.
- Informasi streak.
- Pengingat materi hari ini.
- Menu navigasi.

## 5. Halaman Jadwal Belajar
Halaman untuk melihat dan mengelola jadwal belajar.

Komponen:
- Daftar materi belajar.
- Tanggal belajar.
- Status penyelesaian materi.
- Tombol Buat Jadwal.
- Tombol Tandai Selesai.

## 6. Halaman Career Roadmap
Halaman untuk melihat persiapan karier pengguna.

Komponen:
- Daftar checklist persiapan karier.
- Status setiap checklist.
- Persentase kesiapan karier.
- Kolom alamat profil LinkedIn.
- Tombol Simpan.
- Ringkasan pencapaian belajar.
